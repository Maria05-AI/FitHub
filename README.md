# FitHub 💪

FitHub is a Software Engineering course project designed to manage fitness-related services through a structured and user-friendly system.  
This repository showcases the project as part of a portfolio for demonstration purposes.

---

## Project Overview
FitHub provides functionality for managing users, trainers, and fitness activities, including:

- User registration and authentication
- Profile management
- Trainer assignment and management
- Fitness tracking and reporting
- Data persistence and testing

The system is built with a clear separation between frontend and backend, ensuring maintainability and scalability.

---

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Java / Node.js (according to project implementation)  
- **Database:** SQLite (`fithub.db`)  
- **Development Environment:** NetBeans IDE  

---

## How to Run the Project
1. Clone the repository or download the ZIP file.  
2. Make sure all required dependencies are installed.  
3. Navigate to the `code/project` directory.  
4. Run the backend server using NetBeans or your preferred IDE.  
5. Open the frontend interface (HTML/JS) in a browser.  
6. Follow instructions in `README_FitHub_Setup.md`.
